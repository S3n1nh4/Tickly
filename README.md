# Tickly ⏱️

Tickly é um aplicativo desktop de cronometragem desenvolvido em Java Swing para registrar tarefas e atividades de forma rápida, espontânea e intuitiva.

O aplicativo foi criado para ajudar usuários a acompanhar o tempo dedicado às suas atividades diárias sem necessidade de planejamentos prévios ou configurações complexas. Basta iniciar uma medição, pausar, salvar e acompanhar o tempo total acumulado ao longo do dia.

## Funcionalidades

▶️ Iniciar e pausar cronômetro

⏸️ Modo intervalo

💾 Salvamento de medições

🗑️ Exclusão de registros

⏱️ Soma automática do tempo total

📂 Persistência de dados entre sessões

🖥️ Interface desktop simples e leve

## Tecnologias utilizadas

- **Java** → escolhido tanto pela sua versatilidade quanto pelo meu interesse pessoal em aprofundar o aprendizado da linguagem através de projetos práticos.
- **Java Swing** → utilizado para desenvolvimento da interface gráfica desktop de forma simples e objetiva.

## Objetivo

O Tickly foi desenvolvido como uma ferramenta simples de produtividade e monitoramento de tempo, focada em medições imediatas e espontâneas do cotidiano.

## Sobre o projeto

O Tickly surgiu durante meus estudos como uma forma simples e rápida de registrar o tempo investido nas atividades do dia sem depender de planejamentos ou ferramentas complexas.

A ideia era criar um cronômetro leve e imediato, capaz de acompanhar medições espontâneas durante sessões de estudo, permitindo visualizar o tempo total dedicado às tarefas ao longo do dia.

## Futuro do projeto

O projeto continuará evoluindo com novas funcionalidades voltadas para produtividade, organização e análise de tempo, buscando transformar uma necessidade cotidiana em uma solução prática e acessível.
